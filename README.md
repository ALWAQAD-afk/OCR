# استخراج النصوص من المخطوطات العربية

[![Open In Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/github/{OWNER}/{REPO}/blob/main/arabic_ocr.ipynb)

أداة بسيطة ومجانية بالكامل لاستخراج النصوص من المخطوطات والوثائق العربية المصورة (PDF) باستخدام نموذج الذكاء الاصطناعي **Qwen2-VL-2B**.

## المميزات

- **مجاني ومفتوح المصدر 100%** — لا حاجة لأي مفاتيح API أو رموز وصول أو إعدادات مسبقة.
- **يعمل مباشرة على Google Colab** بمعالج رسومات T4 المجاني.
- **يستخرج النص العربي الكامل** مع الحفاظ على التشكيل والحركات وعلامات الترقيم والصياغات القرآنية والتراثية.
- **يصدّر النتائج تلقائيًا** بصيغتي `.docx` و `.txt` مع تنزيل فوري في المتصفح.

## طريقة الاستخدام

1. اضغط على زر **Open in Colab** أعلاه.
2. اختر **وقت التشغيل ← تغيير نوع وقت التشغيل ← T4 GPU**.
3. شغّل الخلية الوحيدة وارفع ملف PDF عند الطلب.
4. انتظر حتى تكتمل المعالجة — سيتم تنزيل الملفات تلقائيًا.

## المتطلبات

لا شيء سوى حساب Google مجاني وملف PDF.
